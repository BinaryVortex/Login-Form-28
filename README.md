# Login Form

A clean, responsive login form built with HTML, CSS and a touch of JavaScript.

![Login Form Screenshot](https://raw.githubusercontent.com/BinaryVortex/Login-Form-28/main/Screenshot%202024-07-02%20094346.png)


## Description

This repository contains a simple, modern login form UI created as a frontend component. It's implemented with plain HTML, CSS, and JavaScript and is ideal for small projects, prototypes, or learning how to build accessible and responsive forms.

## Features

- Responsive layout that works on desktop and mobile
- Clean, minimalist design
- Customizable styles in `style.css`
- Easy to integrate into any static site or frontend project

## Files

- `index.html` — Markup for the login form
- `style.css` — Styling and layout
- `apple.png`, `google.png` — Social login icons
- `Screenshot 2024-07-02 094346.png` — Project screenshot used above

## Usage

1. Clone or download the repository:

   git clone https://github.com/BinaryVortex/Login-Form-28.git

2. Open `index.html` in your browser to see the form.

3. Customize styles in `style.css` and modify markup in `index.html` as needed.

## Customization tips

- Change colors, fonts, and spacing in `style.css` to match your brand.
- Replace `apple.png` and `google.png` with your own social icons if needed.
- Add form validation or connect the form to your backend by updating the JavaScript in `index.html`.
